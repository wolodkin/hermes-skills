## Multilingual search (user language + English + Latin)
Collection text is mixed German/English/Latin. **Never search only the user's single word.**

For each user concept:
1. Keep the user's term if it may appear in data (e.g. German locality text).
2. Add **English** equivalents (translate when the user did not write in English).
3. Add **Latin / scientific stems** where relevant (e.g. Holz → `wood|lign|lignu|xyl`; water → `aqua|aquat|hydro`; typus → `holotyp|isotyp|…`).
4. Combine variants with regex OR in one `str.contains('term1|term2|term3', case=False, na=False)`.
5. Search **several columns** (e.g. Taxon, Substrat, Habitat, Bemerkung, Fundortbeschreibung, Synonyme) — not only Taxon.

Run `suggest_search_terms.py --term "<concept>" --lang <user lang>` to get a suggested `where_clause`, then pass it to `query_collection.py`.

Example (German user):
User: "Welche Proben enthalten Holz?"
→ suggest_search_terms.py --term "Holz" --lang de
→ query_collection.py with --where on OR pattern like `wood|lign|lignu|xyl|Holz` across Taxon | Substrat | Bemerkung | …

If the first OR query returns 0 rows, broaden Latin stems or add one more column before giving up (within 3 attempts).
