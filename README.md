# hermes-skills

A collection of [Hermes](https://github.com/NousResearch/hermes-agent) agent skills, reusable instructions and scripts that extend what your agent can do in daily work and personal workflows.

Each skill lives in its own folder with a `SKILL.md` (metadata, triggers, and procedure) plus optional scripts and references. Install a skill into your Hermes skills directory, set any required environment variables, and invoke it through natural-language triggers or the bundled tooling.

**HermInE** (*Hermes Interactive Environment*) is the longer-term goal: a cohesive set of skills and integrations that turn Hermes into a practical, personal command environment - not just a chat interface.

Skills are published here as they mature. Contributions and issue reports are welcome.
